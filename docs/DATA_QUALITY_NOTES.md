# Data Quality Notes

## Scope

The artifact preserves the risk-assessment values generated by the
evaluated ThreatSpider build. Stored Batch 12 results are not silently
replaced or retrospectively edited.

## OOI, I2CF, and I2MF Assignment

Inspection of the evaluated implementation showed that the automatic
component-centrality update assigns both I2CF and I2MF using the same
OOI-derived value.

The database snapshot confirms that:

- OOI equals I2CF for all 34 components.
- OOI equals I2MF for all 34 components.
- 51 Batch 12 risk records use I2CF through their consequence mappings.
- No Batch 12 risk record uses I2MF.

The affected I2CF mappings are associated with:

- Denial of Control
- Impair Process Control
- Loss of Control
- Manipulation of Control

The artifact preserves the values stored by the evaluated build.
Independent I2CF and I2MF values are not inferred retrospectively.

## Impact Formula Implementation

The evaluated implementation calculates Impact using:

- Operational
- Safety
- Information
- Financial
- Staging
- Environmental
- Reputation

The implementation also loads factors and component metrics for:

- Confidentiality
- Integrity
- Availability

However, these three contributions are not included in the final Impact
sum in the evaluated code.

The stored Impact values are reproducible from the implemented
seven-element formula within an absolute tolerance of 0.00001. The
maximum observed reproduction difference is 0.0000048, indicating
numeric rounding or serialization rather than a substantive formula
mismatch.

## CIA-Restored Sensitivity Analysis

A separate sensitivity analysis adds the omitted Confidentiality,
Integrity, and Availability contributions while retaining all other
stored inputs, including the stored I2CF values.

Results:

- Batch 12 records: 1513
- Records with a non-zero omitted CIA contribution: 866
- Stored non-tolerable records: 29
- CIA-restored non-tolerable records: 62
- Changed tolerability classifications: 33

These values are sensitivity-analysis results. They must not be described
as definitive corrected risk scores because independent I2CF values are
not available for the 51 records that use I2CF.

## FMMT Mapping Check

The project contains 201 FMMT rows representing 161 unique
consequences. No consequence-element pair has conflicting metric
assignments, and no consequence has multiple distinct mapping
signatures.

See `RISK_FORMULA_AUDIT.md` for the detailed interpretation.
