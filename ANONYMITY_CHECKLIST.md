# Anonymous Review Checklist

This checklist is used before publishing the artifact for double-blind peer review.

## Author and Institution Information

- [ ] No author names appear in repository files
- [ ] No institutional names appear in repository files
- [ ] No institutional email addresses appear in repository files
- [ ] No acknowledgements appear in repository files
- [ ] No funding project names or grant numbers appear in repository files
- [ ] No personal GitHub usernames appear in repository files

## File Metadata

- [ ] Excel document properties have been removed
- [ ] Excel custom XML data has been removed
- [ ] No Word or PowerPoint source documents are included
- [ ] Images contain no identifying EXIF metadata
- [ ] PDFs contain no identifying author metadata

## Local and Technical Identifiers

- [ ] No local Windows paths appear in files
- [ ] No usernames appear in file paths or screenshots
- [ ] No Teams, SharePoint, or institutional URLs appear
- [ ] No database usernames appear
- [ ] No reviewer or analyst names appear in exported records

## Credentials and Sensitive Material

- [ ] No passwords are included
- [ ] No API keys or tokens are included
- [ ] No environment files are included
- [ ] No database dumps are included
- [ ] No Docker images or internal backups are included

## Repository History

- [ ] Repository was initialized as a new repository
- [ ] No previous project Git history was imported
- [ ] Git author name is anonymous
- [ ] Git author email is anonymous
- [ ] Commit signing is disabled
- [ ] Repository contains only review-safe artifacts
